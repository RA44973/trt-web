FDIY · федеральные DIY-сети

Отдельный источник продаж по сетям со статусом FDIY. Можно загрузить одну сеть или несколько сетей, один месяц или исторический период. Историческая загрузка умеет продолжаться после обрыва и пропускает уже сохранённые периоды. Повторная месячная загрузка заменяет только совпавшие сеть + месяц + направление после подтверждения.

Поддерживаемые форматы: Исторический широкий: Направление · Название ТРТ · Адрес · пары «Все / ВОГ» по месяцам Месячный/универсальный: Сеть · Код ТРТ · Название ТРТ · Адрес · Направление · Год · Месяц · Общие продажи · Продажи ВОГ Для файла одной сети столбец «Сеть» можно не заполнять — используется выбранная сеть. Если в месячном файле нет Года/Месяца, используется период, выбранный выше.

Плитка · сценарка

Загрузка структуры и плана: Регион → Город → Клиент → ТРТ → номенклатурная группа. План хранится на уровне ТРТ × НГ × месяц; регион, город, клиент и менеджер рассчитываются автоматически.

Берём в работу:A:E — структураBN:BY — план Янв–ДекCI,CJ,CK,CM,CN,CO,CQ,CR,CS,CU,CV,CW — факт по НГ для детализацииBM и CG — только контрольные итоги
Факт ТРТ не перезаписывается. Если факт сценарки расходится с текущими продажами в базе, в аналитике остаётся факт из базы. Факт из сценарки хранится отдельно только для разреза по НГ и контроля.
