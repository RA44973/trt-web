ПРИГЛАШЕНИЕ СОТРУДНИКА ЧЕРЕЗ ЯНДЕКС ПОЧТУ

Отправитель
razguliaev.alex@yandex.ru

Как работает
- Админ ГД нажимает «Пригласить» напротив сотрудника.
- Система создаёт новый временный пароль.
- Письмо содержит логин, временный пароль, ссылку на МП
  и инструкции установки для Android и iPhone.
- Во время теста все письма приходят на:
  a.razgulyaev@vogtrade.ru
- После теста переменная INVITE_TEST_RECIPIENT удаляется,
  и письма отправляются на корпоративную почту сотрудника.
- Если отправка письма не удалась, старый пароль сотрудника
  автоматически восстанавливается.

Cloud Postbox
Cloud Postbox и настройка DKIM для vogtrade.ru в этой версии не нужны.
Отправка выполняется через защищённый SMTP Яндекс Почты.

Нужные переменные Cloud Function
SMTP_FROM_EMAIL=razguliaev.alex@yandex.ru
SMTP_USERNAME=razguliaev.alex@yandex.ru
SMTP_APP_PASSWORD=<пароль приложения Яндекс Почты>
INVITE_TEST_RECIPIENT=a.razgulyaev@vogtrade.ru
INVITE_APP_URL=https://ra44973.github.io/trt-mobile/

Важно
- Не используйте обычный пароль от Яндекс ID.
- Создайте отдельный пароль приложения типа «Почта».
- Пароль приложения вводите только в переменную окружения
  Cloud Function. Не отправляйте его в чат и не сохраняйте в GitHub.
- Яндекс указывает, что новый пароль приложения может начать
  действовать не сразу.

Установка
1. Обновить Cloud Function архивом:
   Cloud_Function_Приглашение_через_Яндекс_Почту.zip
2. Обновить сайт архивом:
   Сайт_Кнопка_Пригласить_SMTP.zip
3. Добавить перечисленные переменные окружения в Cloud Function.

API Gateway, YDB и мобильное приложение менять не требуется.
