VOG Мобильный помощник — Web v7.5
Логистика: поддержка нового отчёта 1С, где адрес идёт второй строкой после клиента.

Установка:
1. Распаковать ZIP.
2. Загрузить все файлы в репозиторий GitHub Pages с заменой.
3. Дождаться публикации.
4. Выполнить Command + Shift + R.

Изменения:
- адресная строка больше не считается отдельной доставкой;
- сопоставление выполняется по комбинации «получатель + адрес + направление»;
- в ручной проверке отображается адрес и качество адресного совпадения;
- одно подтверждение сохраняется для конкретного получателя и адреса.
