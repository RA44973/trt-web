VOG Мобильный помощник — обновление импорта продаж

Изменение:
- пустая ячейка в колонке «Количество» означает отсутствие продаж за месяц;
- такая строка получает статус «Нет продаж», не считается ошибкой и не загружается в YDB;
- текст, отрицательное число или другое некорректное непустое значение по-прежнему считается ошибкой.

Установка:
1. Yandex Cloud → trt-api → Редактор: заменить содержимое index.py и создать версию.
2. GitHub trt-web: заменить index.html, app.js, styles.css.
3. Обновить страницу с очисткой кэша.
