VOG Мобильный помощник

Обновлено:
- название в мобильном приложении;
- название устанавливаемой PWA;
- название веб-кабинета и вкладки браузера;
- название в письме-приглашении;
- тема письма;
- кнопка письма изменена на «Установить приложение»;
- кнопка увеличена, сделана заметнее и более прямоугольной.

Порядок установки:
1. Cloud Function:
   Cloud_Function_VOG_Мобильный_помощник_и_письмо.zip
2. Сайт:
   Сайт_VOG_Мобильный_помощник.zip
3. МП:
   МП_VOG_Мобильный_помощник.zip

В МП заменить:
- app.js;
- sw.js;
- manifest.webmanifest.

YDB и API Gateway менять не требуется.

Примечание:
- внутри уже установленного приложения новое название интерфейса появится
  после обновления;
- подпись иконки на домашнем экране некоторых телефонов может обновиться
  не сразу;
- все новые установки будут сразу называться «VOG Помощник».
