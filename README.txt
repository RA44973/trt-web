ПРИГЛАШЕНИЕ СОТРУДНИКА В МОБИЛЬНОЕ ПРИЛОЖЕНИЕ

Что добавлено
- В разделе «Сотрудники» появилась кнопка «Пригласить».
- Кнопка доступна только Админу ГД.
- Перед отправкой система создаёт новый временный пароль.
- В письме указаны логин, временный пароль, ссылка на приложение,
  инструкция установки для Android и iPhone.
- После успешной отправки прежние сеансы сотрудника закрываются.
- Если письмо не отправилось, прежний пароль автоматически восстанавливается.

Тестовый режим
В Cloud Function задаётся переменная:
INVITE_TEST_RECIPIENT=a.razgulyaev@vogtrade.ru

Пока переменная существует, любое приглашение будет доставляться на
a.razgulyaev@vogtrade.ru, но внутри письма будут данные выбранного сотрудника.

После успешного теста удалить переменную INVITE_TEST_RECIPIENT.
Тогда письма будут отправляться на корпоративную почту сотрудника.

Отправка почты
Используется Yandex Cloud Postbox и IAM-токен сервисного аккаунта функции.
Почтовые пароли или API-ключи в функции не хранятся.

Перед использованием:
1. Создать и верифицировать адрес отправителя в Yandex Cloud Postbox.
2. Назначить сервисному аккаунту trt-app-backend роль postbox.sender.
3. Добавить в Cloud Function переменные:
   POSTBOX_FROM_EMAIL=<верифицированный адрес отправителя>
   INVITE_TEST_RECIPIENT=a.razgulyaev@vogtrade.ru
   INVITE_APP_URL=https://ra44973.github.io/trt-mobile/

Установка:
1. Обновить Cloud Function архивом Cloud_Function_Приглашение_сотрудника.zip.
2. Обновить сайт архивом Сайт_Кнопка_Пригласить.zip.
3. API Gateway менять не требуется: используется существующий POST /employees.
4. YDB и МП менять не требуется.
