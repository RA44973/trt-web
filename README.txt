ОБНОВЛЕНИЕ — ВТОРОЙ ГД БЕЗ ПРАВ АДМИНИСТРАТОРА

Новая модель
1. Роль ГД:
- доступ ко всем ТРТ и направлениям;
- доступ ко всем визитам, задачам, фото, рейтингам и продажам;
- не зависит от направления и подчинённости.

2. Администратор:
- отдельный системный признак;
- видит раздел «Сотрудники»;
- добавляет сотрудников и управляет учётными записями;
- административные права через интерфейс не назначаются.

Результат
- текущий Админ ГД остаётся единственным администратором;
- через форму можно добавить второго ГД;
- второй ГД видит все рабочие материалы;
- второй ГД не видит раздел «Сотрудники»;
- прямые запросы второго ГД к административным API отклоняются.

Как добавить второго ГД
На сайте открыть:
Сотрудники → + Сотрудник

В поле «Роль» выбрать:
«Генеральный директор — без прав администратора»

Для этой роли:
- направление не требуется;
- непосредственный руководитель не требуется;
- административные права не выдаются.

Установка
1. Обновить Cloud Function архивом:
   Cloud_Function_ГД_без_прав_администратора.zip
2. Обновить сайт архивом:
   Сайт_ГД_без_прав_администратора.zip

Новый SQL не требуется.
МП и API Gateway менять не требуется.
