ОБНОВЛЕНИЕ РЕЙТИНГА ТРТ ПО СХЕМЕ ИЗ ФАЙЛА «Визит в МП.pdf»

Изменено:
- плоский компактный блок «Рейтинг ТРТ» без секций Place/Product/Promotion;
- три ручные оценки меняются нажатием на зелёную оценку;
- кнопка «?» открывает подробную методику оценки;
- вводится общее количество SKU и количество SKU ВОГ; доля рассчитывается автоматически;
- коммерческие условия не редактируются и ожидают данных системы КУ;
- мотивация рассчитывается по доле продавцов в VOG Club;
- итоговый рейтинг виден сверху;
- новая структура отображается в карточке ТРТ и визита на МП и сайте;
- старые оценки версии 1 продолжают отображаться.

Принятое допущение:
оценка мотивации: 1=0%, 2=1-25%, 3=26-50%, 4=51-75%, 5=76-100%.
Эти границы можно изменить после утверждения.

Установка:
1. Cloud Function: загрузить Cloud_Function_Рейтинг_ТРТ_v2.zip в trt-api.
2. Сайт: заменить файлы из Сайт_Рейтинг_ТРТ_v2.zip в trt-web.
3. МП: заменить app.js и sw.js из МП_Рейтинг_ТРТ_v2.zip в trt-mobile.
API Gateway и YDB менять не требуется.
