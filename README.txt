VOG Web v8.26 — русские подписи карт + удобный поиск адреса новой ТРТ.

Что изменено:
- на основной карте и карте ручного добавления ТРТ используются подложки без встроенных подписей;
- городские подписи формируются самим VOG Web на русском; для Беларуси явно добавлены Минск, Брест, Витебск, Гомель, Гродно, Могилёв;
- системный Leaflet prefix отключён на всех Leaflet-картах, поэтому посторонний значок перед Leaflet больше не выводится;
- в форме «+ Добавить ТРТ» адрес подсказывается по мере ввода начиная с 3 символов;
- можно искать неполно: например «Минск Тимиряз»;
- если выбрана улица без дома, карта приближает улицу и просит дописать номер дома или поставить точку вручную;
- при выборе полного адреса координаты проставляются автоматически;
- обратное определение адреса по клику карты запрашивается на русском.

Backend API остаётся v6.27. API Gateway и YDB менять не нужно.
Для обновления заменить app.js и index.html в корне trt-web, commit в main и выполнить hard refresh.
