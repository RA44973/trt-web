ДОБАВЛЕНИЕ СОТРУДНИКОВ — АДМИНИСТРАТИВНЫЙ МОДУЛЬ

Доступ
- Раздел «Сотрудники» видит только ГД.
- Добавлять сотрудников может только ГД.
- Сервер отклоняет прямые запросы пользователей других ролей.

Что создаётся при добавлении сотрудника
1. Карточка сотрудника.
2. Роль доступа: КД, РРО или Менеджер.
3. Направление: Плитка или Обои.
4. Связь с непосредственным руководителем.
5. Учётная запись для сайта и МП.
6. Логин — корпоративная почта.
7. Пароль — временный пароль, который указывает ГД.

Правила иерархии
- КД подчиняется ГД.
- РРО подчиняется ГД или КД.
- Менеджер подчиняется ГД, КД или РРО.
- Если руководитель не ГД, направление сотрудника должно совпадать
  с направлением руководителя.
- Добавление ещё одного ГД через интерфейс запрещено.

Порядок установки
1. Один раз выполнить SQL:
   01_Создать_таблицу_добавления_сотрудников.sql
2. Обновить Cloud Function trt-api архивом:
   Cloud_Function_Добавление_сотрудников.zip
3. Обновить сайт trt-web архивом:
   Сайт_Добавление_сотрудников.zip

Настройки Cloud Function не менять:
- Python 3.12
- точка входа index.handler
- память 256 МБ
- таймаут 10 секунд
- сервисный аккаунт и переменные окружения оставить текущими

API Gateway и мобильное приложение менять не требуется.

После установки
На сайте открыть «Сотрудники» → «+ Сотрудник».
Заполнить:
- полное ФИО;
- роль;
- направление;
- непосредственного руководителя;
- корпоративную почту;
- временный пароль.

После сохранения сотрудник может войти по этой почте и паролю
и увидит данные согласно своей роли и иерархии.

Важно
Новый менеджер не увидит ТРТ, пока его клиентская база не будет
привязана к его employee_id. Это отдельная операция распределения ТРТ.
